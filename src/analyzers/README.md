# Analyzers - Bộ phân tích

Thư mục điều phối việc trích xuất đặc trưng (Orchestrator).

- `audio_analyzer.py`: Chạy tổng hợp tất cả các Audio Features.
- `video_analyzer.py`: Chạy tổng hợp tất cả Video Features.
- `transcription_analyzer.py`: Trích xuất phụ đề qua Whisper.
- Muốn sửa cách tính tổng điểm? Thay đổi logic trong file analyzer tương ứng.
